# Add a read-only royalty report

Read the schema and the operator's question. Write a read-only query with period and currency visible. Add the report to views.json, then run npm run view. Inspect the generated HTML for correct figures, unknown values and layout. Do not add forms, buttons that change records or a web application. A provisional calculation must be labelled. Keep generated private files out of git.
