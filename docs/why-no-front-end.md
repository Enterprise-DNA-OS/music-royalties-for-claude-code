# Views without a front end

The weekly job is checking income, recording agreed rules and reviewing the close. Ask the agent to run the CLI and present the result. npm run view renders read-only HTML for the week, source income and recoupment. npm run docs renders statement working papers and source-reconciliation packs. There is no running web server and no action button.

A dedicated screen adds mobile access, staff sign-in, recipient portals, drag-and-drop catalogue work and collaborative review. This base does not supply those. Enterprise DNA can build the agreed interface and connections into your version. Direct SQL and local filesystem access are administrator capabilities, not a staff permission system.

Edit brand.json for your own business name, colours and logo. Use /new-view for another read-only question. Generated documents can contain private source records: keep them in controlled storage and review before sharing.
